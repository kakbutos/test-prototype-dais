# Поддержка шаблона

Шаблон не обновляет чужие проекты автоматически. Новые копии получают файлы текущей версии; уже созданные проекты независимы.

## Зависимости

Исходная связка: React 18.3.1, Dais 1.27.0, MCP 0.2.10, styled-components 5.3.1. Dais использует форк Glide 6.11.0. Overrides удерживают sdds-finai 0.361.0 и plasma-icons 1.252.0: новые минорные версии атомарной библиотеки могут менять peer requirements. Все транзитивные версии фиксирует lockfile.

Для нового проверенного набора версий:

1. Создайте ветку. Обновите намеренно выбранные версии и совместимые overrides. Не переключайте всё на latest.
2. Пересоздайте lockfile обычным npm install без force/legacy-peer-deps.
3. Выполните чистый npm ci вне монорепозитория, doctor, mcp:check, build, `npm run export:html -- collection` и npm test. Откройте сайт и итоговый HTML доступным браузером, проверьте затронутые действия и шрифты; браузерных автотестов в проекте нет. Проверьте, что индекс MCP соответствует установленному пакету.
4. Проверьте старые варианты и начальное состояние и сброс после перезагрузки. Зафиксируйте версию шаблона и результат проверки.

Для существующего дизайнерского проекта обновляйте зависимости и служебные файлы отдельным diff. Не заменяйте `src/prototypes`, `.git`, настройки аккаунта и локальные конфиги MCP. Обновления skills редактируются в `.agents/skills`, затем `npm run skills:sync` создаёт копии для Claude/GigaCode. После перемещения папки перезапустите setup для новых абсолютных путей MCP.

## Новый сценарий

Самодостаточный пример должен собираться на опубликованном пакете. Не переносите внутренние `@ui-kit`/`@df-storybook` импорты. Примеры MCP иногда содержат ссылки на не включённые helper-функции — допишите явные данные и обработчики в consumer-приложении.

В галерее обнаруживаются `src/prototypes/*/index.tsx`. Имя папки — ID hash-route. `meta` содержит title/description/category; default export — экран. Состояние демо хранится в памяти компонента и сбрасывается при повторном открытии. Постоянное начальное состояние задаётся в коде; браузерное хранилище для него не используется. Изменения общей композиции затрагивают все использующие её варианты.
