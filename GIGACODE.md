# Dais prototypes

Прочитай `AGENTS.md`. Для GigaCode CLI навыки находятся в `.gigacode/skills`.
Подготовка: прочитай `.agents/skills/dais-setup/SKILL.md` и выполни `npm run setup`.
CLI получает MCP из `.gigacode/settings.json`; VS Code — из `.gigacode_vsc/gigacode.jsonc`.
Выбор результата описан в AGENTS.md: HTML-файл — `.agents/skills/dais-export-html/SKILL.md`; ссылка на GitHub Pages через Actions — `.agents/skills/dais-publish/SKILL.md`. Можно пока работать только локально. Если выбор уже указан, не спрашивай повторно.
Для клиента, который не подхватил навыки автоматически, можно попросить прочитать SKILL.md напрямую.
Поддержка изображения и выполнение команд зависят от возможностей клиента, выбранной модели и режима работы. Не утверждай, что видел PNG, если клиент его не передал.
